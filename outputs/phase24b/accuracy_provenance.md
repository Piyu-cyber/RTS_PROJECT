## 1. Executive Summary

This document establishes the official scientific provenance of all accuracy quantities reported in this research. To eliminate the ambiguities identified in earlier phases, we strictly define and separate three distinct accuracy metrics:

1. **Validation Accuracy ($\text{Acc}_{\text{val}}$):** Evaluated offline on the 736-image validation split. Used exclusively for model profiling and quality threshold gating ($\tau_{\text{qual}} \ge 92.0\%$).
2. **Synthetic Expected Test Accuracy ($\mathbb{E}[\text{Acc}_{\text{test}}]$):** A model-weighted expectation over completed requests based on Phase 23B full-dataset test set benchmarks. Formally labeled as synthetic/estimated.
3. **Empirical Test Accuracy ($\text{Acc}_{\text{empirical}}$):** Evaluated by executing physical inferences of captured CUDA Graphs on the NVIDIA RTX 4060 GPU using real Oxford-IIIT Pet test images.

## 3. Dissecting the Accuracy Metrics

### 3.1 Validation Accuracy (Quality Gating)
To prevent runtime token pruning from violating classification requirements, candidate models must satisfy an explicit quality threshold:
$$\mathcal{M}_{\text{eligible}} = \{m \in \mathcal{M} \mid \text{Acc}_{\text{val}}(m) \ge \tau_{\text{qual}}\}, \quad \tau_{\text{qual}} = 92.0\%$$
- All 4 models qualify because the most aggressive configuration (`evit_small_k05_fuse`) achieves $92.53\% \ge 92.0\%$.
- **Test Set Protection:** The test partition (`test.txt`, 3,669 images) was **never** accessed during threshold tuning or online model selection decisions.

### 3.2 Synthetic Expected Test Accuracy (Simulation)
In discrete-event simulation, tensor inference is not executed on image files. Instead, accuracy is computed as the model-weighted expectation over completed requests:
$$\mathbb{E}[\text{Acc}_{\text{test}}] = \frac{\sum_{i=1}^{N_{\text{comp}}} \text{Acc}_{\text{test}}(m_i^*)}{N_{\text{comp}}}$$
Across all 10 canonical simulation workloads (796 completed requests under `EDF_Adaptive_AC`):
- `deit_small_baseline`: 691 dispatches ($86.8\%$) $\times 92.67\%$
- `evit_small_k09_fuse`: 48 dispatches ($6.0\%$) $\times 92.75\%$
- `evit_small_k07_fuse`: 20 dispatches ($2.5\%$) $\times 93.19\%$
- `evit_small_k05_fuse`: 60 dispatches ($7.5\%$) $\times 91.44\%$
$$\mathbb{E}[\text{Acc}_{\text{test}}] = \frac{691(92.67) + 48(92.75) + 20(93.19) + 60(91.44)}{796} = \mathbf{92.60\%}$$
This reflects an expected quality drop of only **$0.07$ percentage points** relative to the full unpruned DeiT baseline ($92.67\%$).

### 3.3 Empirical Classification Accuracy (Physical RTX 4060 GPU Replay)
When replaying workloads on physical hardware using real JPEG images from `datasets/oxford-iiit-pet/`, predictions are generated by forward passes through captured CUDA Graphs:
$$\text{Acc}_{\text{empirical}} = \frac{\sum_{i=1}^{N_{\text{comp}}} \mathbb{I}(\hat{y}_i = y_i)}{N_{\text{comp}}} \times 100\%$$
On the replayed workloads:
- `periodic_mod_mod`: **89.0 %** (89 / 100 correct)
- `bursty_high_tight`: **87.5 %** (70 / 80 correct)
- `overload_tight_deadline`: **91.3 %** (42 / 46 correct)
These empirical results reflect small-sample binomial variance ($N = 46\text{ to } 100$) around the asymptotic dataset expectation.

## 4. Denominator & Conditioning Disclosures

1. **Conditional Goodput Metric:**
   Accuracy is strictly evaluated over **completed requests** ($N_{\text{completed}}$).
   $$\text{Accuracy} = \text{P}(\hat{y} = y \mid \text{Request Completed})$$
2. **Rejected and Expired Tasks:**
   Requests that are rejected by admission control ($N_{\text{rejected}} = 24$ in `periodic_high_tight`) or expired in the queue never execute on the GPU. They receive no prediction and are accounted for in the **On-Time Completion Rate** ($N_{\text{ontime}} / N_{\text{offered}} = 76.0\%$).
